# ONNMY Freelook

Fabric client-side mod for Minecraft 1.21.11.

## Features
- F5 toggles Freelook mode.
- Client-side only.
- Designed for Fabric 1.21.11 / Java 21.
- TAB uses the normal Minecraft player list.

## Build
```bash
./gradlew build
```

The compiled jar will be in `build/libs/`.

## Requirements
- Minecraft Java 1.21.11
- Fabric Loader
- Fabric API
- Java 21
